## Octo Chat public baseline

## 2.2.0

This release establishes **Octo Chat** as the canonical product and repository identity.

The supported public release platforms are **Windows and Linux**.

- The application, companion extension, MCP connector names, package metadata, release artifacts and updater now use Octo Chat branding.
- The canonical source repository is `Shattermoon/octo-chat` and begins from a clean public root commit. Community work incorporated before the reset remains credited in `CONTRIBUTORS.md`.
- Bridge protocol 14 makes the application-identity change explicit; reload the matching companion extension after updating.
- macOS publication is paused. Current release CI packages and smoke-tests Windows x64/ARM64 and Linux x64/ARM64 only.
- Native Desktop automation is currently a Windows product surface. Linux continues to provide Core, Plugins and the companion workflow without Desktop control.

**Reload the companion extension and refresh the Octo Chat connectors in ChatGPT after updating.**

### Downloads

| Platform | Files |
| --- | --- |
| Windows | `Octo-Chat-Setup-x64.exe` · `Octo-Chat-Setup-arm64.exe` |
| Linux x64 | `Octo-Chat-Linux-x64.AppImage` · `Octo-Chat-Linux-x64.deb` |
| Linux ARM64 | `Octo-Chat-Linux-arm64.AppImage` · `Octo-Chat-Linux-arm64.deb` |

Also included: `Octo-Chat-Extension.zip`, `Octo-Chat-Native-Sources.tar.gz` (corresponding native-library sources and replacement instructions), and `SHA256SUMS.txt`.

Windows release binaries are currently publisher-unsigned, so Windows SmartScreen may warn. Verify `SHA256SUMS.txt` before running a downloaded installer.

On Linux, prefer the DEB on Debian/Ubuntu. The AppImage can fall back to `--no-sandbox` when the host disables unprivileged user namespaces; this fallback is covered by release smoke tests.
