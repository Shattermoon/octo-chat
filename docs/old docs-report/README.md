# Historical docs and reports

This directory contains engineering audits, incident notes, implementation plans and integration snapshots from earlier Octo Chat revisions. They are kept for provenance and regression context; **they are not the current product contract**.

Use these current sources first:

- [Full 2026-09-14 audit](../octo-chat-full-audit-2026-09-14.md) — authoritative finding set that superseded the earlier audit draft.
- [Two-maintainer remediation program](../remediation-program-2026-09-14.md) — current PR/dependency/ownership plan.

- [`SECURITY.md`](../../SECURITY.md) — current public security model.
